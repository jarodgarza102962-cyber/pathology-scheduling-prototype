# 1. 概述

本模块用于病理科实验室与分子病理实验室对科室人员排班、工位调度、岗位规则维护以及排班任务执行协同进行统一管理。系统以 **“岗位能力准入、周期矩阵编排、待办任务自动派发、全员执行协同与闭环核销”** 为核心业务闭环，全面解耦检测岗位、实验方法、检测靶标与日常辅助杂务，满足 CNAS-CL02 及病理实验室质量管理体系中关于人员技术资质准入、关键岗位双签质控、房间安全巡检及日常职责溯源的管理要求。

## 1.1 关联需求与业务背景
1. **需求 XQ_261027001（分子科四层排班解耦与多轨并行）**：分子实验室日常涉及高通量测序(NGS)、荧光原位杂交(FISH)、Sanger重排测序、荧光定量PCR等多条复杂技术路线，且包含季度工位轮换、长期物料A/B角包干及11名人员轮转7个物理房间的安全巡检。系统将“检验项目”、“实验工位”与“辅助杂务（如切蜡块、转运送检）”分轨运行与独立统计。
2. **需求 XQ_261027002（资质白名单准入与自动防呆）**：读取人员技术档案与授权结果，严禁未经授权人员排入特定分子检测岗位；对关闭兼任的主技术岗位执行同日互斥拦截，对日常辅助类岗位放行并行兼任。
3. **需求 XQ_261103001（排班与任务闭环联动）**：排班发布后，支持一键发起排班待办，系统自动依据岗位绑定的工作指引及任务模板批量实例化为个人待办日程清单，并在独立的“待办任务”工作台支持组长与员工实时跟踪进度与闭环打勾。

## 1.2 科室排班特征与核心解耦原则
1. **病理科（临床业务任务调度型）**：以诊断任务与会诊任务为调度中心。日常由送检标本量和病理切片类型触发，排班分为按工作日/院区分布的诊断常规岗位，以及按专家个人分配的会诊、质控和带教任务。核心业务处理为任务指派与工作量/津贴核算。
2. **分子科（实验室流程与能力调度型）**：以合规资质与多维职责覆盖为调度中心。分子实验室具有强流程性与严苛的质量合规（如 ISO 15189）要求。日常运作包含检测工位、季度技能轮换、长期辅助与质控责任（A/B 双人负责制）以及每日物理房间安全巡视（平移轮转）。核心业务处理为人员胜任能力匹配与多维职责覆盖。
3. **概念四层解耦**：岗位/工位(Post) ≠ 检测方法(Method) ≠ 检测项目/靶标(Item) ≠ 辅助任务(AuxTask)。辅助任务（如切蜡块、转运、试剂盘点、SOP等）独立建库管理，单独指派与统计，不计入临床检验项目量。
4. **同名异法独立建项**：同一临床靶标因检测方法不同而分属不同工位时，独立建项。如 WT1 拆分为 `WT1-PCR` (归属PCR岗) 与 `WT1-FISH` (归属FISH分析岗)；`PDGFRA突变(PCR)` 与 `PDGFRA/KIT(测序)` 拆分管理。
5. **轻量资质匹配**：资质映射为岗位与人员的“胜任池（competent_pool）”，在排班时作为前置下拉过滤依据。
6. **多轨并行与平移解耦**：检测主班岗、A/B辅助质控责任、物理房间巡检三轨并行解耦，独立平移轮换。

# 2. 功能页面一：综合排班工作台（大看板）

页面作为排班系统日常默认看板，用于展示全科室全景排班矩阵、大周期批量排班统筹以及一键发起待办任务派发。

## 2.1 顶部控制栏

### 2.1.1 筛选条件区
1. **视图模式切换**：
   - 控件类型：分段单选按钮组（【按日】/【按月】）。
   - 默认状态：默认选中【按日】。
   - 联动规则：
     - 选中【按日】：大看板切换为月度按日矩阵，横轴按周次展开具体公历日期；日期选择器支持精确到年月；展示日度精细排班网格；
     - 选中【按月】：大看板切换为全年度月度总览矩阵，横轴自适应平铺展开 1-12 月；日期选择器联动切换为年份选择；用于宏观核验全科各工位全年度轮换与人员覆盖。
2. **日期选择器**：
   - 控件类型：紧凑型年月/年份选择组件。
   - 默认展示：按日模式下默认展示当前年月（如 `2026年 11月`）；按月模式下展示当前年份（如 `2026 年`）。
   - 联动规则：
     - 按日模式：选择具体年月后，重新计算当月全部周次起止日期并刷新网格数据；
     - 按月模式：切换年份后，重新加载并渲染该年度 1-12 月的全景月度排班。
3. **岗位大类**：
   - 控件类型：下拉选择框。
   - 选项内容：全部岗位大类、分子检测技术、分子项目审核与报告、常规技术、常规病理诊断、样本与流转管理、试剂/设备/物料管理、质量与安全管理。
   - 默认状态：默认选中“全部岗位大类”。
   - 联动规则：切换时过滤排班矩阵中的岗位大类分组行，非所选大类岗位隐藏。
4. **专业组**：
   - 控件类型：下拉选择框。
   - 选项内容：全科室 / 全部专业组、分子检测组、病理诊断组。
   - 默认状态：默认选中“全科室 / 全部专业组”。
   - 联动规则：与岗位大类叠加过滤，仅展示匹配专业组的岗位行。
5. **人员高亮定位**：
   - 控件类型：下拉选择框。
   - 选项内容：包含科室全部在职人员姓名。
   - 默认状态：默认选中“请选择”。
   - 联动规则：选中具体人员后，矩阵中所有包含该人员的单元格高亮显示，其余单元格弱化显示；选择“请选择”恢复默认显示。

### 2.1.2 页面顶部操作区
1. **【发起待办】**：
   - 使用条件：具有按钮权限。
   - 处理逻辑：点击打开【发起排班待办】弹窗 (`#modalLaunchTodo`)，默认带入当前大盘周期起止日期并扫描有效排班岗位，用于将当前排班网格正式批量实例化派发为员工待办清单（详细规格参见第 3.4 节）。
2. **【批量排班】**：
   - 使用条件：具有按钮权限，默认主操作。
   - 处理逻辑：点击打开【批量排班安排】全景工作台 (`#modalBatchSchedule`)。
3. **【排班规则维护】**：
   - 使用条件：具有按钮权限。
   - 处理逻辑：点击打开【岗位与排班规则维护中心】弹窗 (`#ruleConfigPageOverlay`)。

## 2.2 排班矩阵主体

### 2.2.1 结构层级与视图模式差异
* **第一列（工作岗位/方法/检测项目）**：靠左固定冻结。包含岗位名称加粗文本、专业组与岗位类型标签、关联任务/项目明细（项目间使用 `·` 分隔，超长单行省略带悬浮提示）。
* **横向表头与网格结构（随视图模式自适应切换）**：
  * **【按日模式】（默认工作模式）**：
    * 表头为双层置顶冻结表头：第一层按自然月合并展示，第二层展示具体日期与星期，区分“今天”高亮列标识、工作日 `[班]` 与公休日 `[休]` 角标；
    * 网格按日展开当月各天，单元格内展示日度实际在岗人员姓名标签；
    * 适用于日常排班精细管理与宏观通览。
  * **【按月模式】（年度宏观总览模式）**：
    * 表头为年度置顶表头，横向自适应平铺展开整年度 12 个月份（1月 至 12月）；
    * 单元格内呈现各工位在当月的主责人员；
    * 适用于分子科季度轮转、年度技能培养与各工位长期人员覆盖的宏观通览。

### 2.2.2 排班单元格展示规则（按人数阶梯自适应与溢出气泡）
针对排班网格中的数据单元格，系统根据所排入的人数采取**“纵向堆叠 + 溢出角标 + 悬浮全览”**的自适应展示机制：

1. **单人排班（1 人）**：
   - 单元格居中展示 1 个标准的纯文本药丸标签（如 `张明`）；
   - 鼠标悬浮在单元格上时，通过 Tooltip 原生浮层展示完整姓名提示（如：`排班人员：张明`）。
2. **双人排班（2 人）**：
   - 采用**垂直紧凑堆叠**布局（上下各 1 个姓名标签，如上方 `张明`、下方 `李华`）；
   - 标签高度与字号自适应紧凑排布，确保单元格整洁不撑高溢出、网格规整；
   - 鼠标悬浮在单元格上时，通过 Tooltip 原生浮层展示全部名单（如：`全部排班人员：张明、李华`）。
3. **三人及以上排班（≥3 人，溢出截断与数字气泡）**：
   - 单元格内**最多直接展示前 2 位人员姓名标签**：
     - 上层展示第 1 位人员标签（如 `张明`）；
     - 下层展示第 2 位人员紧凑标签，紧随其后附带一个浅蓝底数字气泡角标（如 `李华` `+1` 或 `+2`，数字代表剩余未展示人数）；
   - 鼠标悬浮在单元格或 `+N` 气泡角标上时，自动触发 Tooltip 浮层，完整显示该单元格包含的全部在岗人员名单（如：`全部排班人员：张明、李华、王建`）。
4. **空缺/待排班格（0 人）**：
   - 显示浅灰色提示文本（`+ 点击排班` 或未排班占位符）。
5. **周末公休格**：
   - 表头带公休日 `[休]` 角标，单元格背景默认标识为公休灰色底色，默认不排班。
6. **按月模式：月度概览格**：
   - 切换至【按月】模式时，单元格展示当月负责人员姓名，鼠标悬浮显示当月负责人员信息。

## 2.3 单日排班弹窗

### 2.3.1 弹窗字段明细
1. **排班日期**：单行文本输入框，只读禁用。自动回显所选单元格对应公历日期与星期（格式如 `2026-11-03 周二`）。
2. **岗位名称**：单行文本输入框，只读禁用。自动回显所选单元格对应岗位名称（格式如 `PCR岗 1`）。
3. **所属专业组**：单行文本输入框，只读禁用。自动回显所选岗位所属专业组（格式如 `分子检测组`）。
4. **排班人员**：
   - 控件类型：下拉选择框。
   - 约束说明：必填项。
   - 下拉数据源：严格仅加载排班规则中该岗位胜任人员名单。

### 2.3.2 页面操作
1. **【取消】**：
   - 处理逻辑：点击单元格数据保持不变，直接关闭弹窗。
2. **【确定】**：
   - 可用条件：必填项已选。
   - 处理逻辑：点击后按序执行以下业务逻辑：
     - 步骤 1（非空校验）：校验排班人员是否已选，未选提示“请选择排班人员”；
     - 步骤 2（排班日期冲突校验）：校验所选人员在当天是否已排入其他“非兼任”的主岗位。若冲突，弹出 Toast “当前人员排班冲突”，并高亮人员选择框及人员姓名；
     - 步骤 3：校验通过后，关闭弹窗并更新对应单元格排班责任人，弹出成功提示“排班保存成功”。

## 2.4 批量排班全景工作台 (`modalBatchSchedule`)

用于月初编制周期底稿、季度核心骨干轮换、物理房间日常轮转等统筹排班场景。点击大看板顶部 `[批量排班]` 唤起。系统遵循“一次批量操作处理一种排班模式；按岗位增量合并生效”的口径。

### 2.4.1 控制区表单字段
1. **开始时间**：
   - 控件类型：日期选择输入框 (`#batchStartDate`)。
   - 约束说明：必填项，默认带入当前周期起始工作日（如 `2026-11-02`）。
   - 联动规则：修改后联动更新明细表中可排日期的计算基准。
2. **结束时间**：
   - 控件类型：日期选择输入框 (`#batchEndDate`)。
   - 约束说明：必填项，默认带入当前周期结束日期；结束时间不得早于开始时间。
   - 联动规则：时间范围变更时触发明细表对应周期列的刷新。
3. **仅工作日**：
   - 控件类型：复选框（Checkbox，`#batchWorkdayOnly`，置于【结束时间】右侧）。
   - 默认状态：**默认勾选**。
   - 日历联动规则：
     - **工作日判定基准**：严格联动系统后台【日历设置】中的排班日历（蓝标【班】与红标【休】）；
     - **纳入排班的工作日**：系统日历中标记为“上班”的日期，包括常规工作日（周一至周五扣除法定节假日放假）以及法定调休补班的周六/周日；
     - **自动跳过的非工作日**：系统日历中标记为“休息”的日期，包括常规周末以及落在周一至周五的法定休假日。
   - 业务处理逻辑：
     - **勾选状态（默认）**：所选起止范围内仅向系统日历标记为“上班”的工作日生成排班，非工作日（法定放假日及普通周末）自动跳过，不排入人员；
     - **未勾选状态**：忽略系统休假标记，所选周期内的所有自然日全量排入人员，适用于急诊值班或每日连续巡检岗位。
4. **排班类型**：
   - 控件类型：单选按钮组 (`name="batchSplitType"`)。
   - 约束说明：单选互斥。
   - 选项内容：包含 5 种业务模式：时间段固定、每日轮转、按每周、按每月、按季度。
   - 联动规则：
     - 选【时间段固定】：起止时间内责任人固定不变，结合【仅工作日】设置自动跳过休假日；
     - 选【每日轮转】：工作日环形错位平移轮转，下方联动显示“轮空天数”字段，明细表切换为配置首日基准人；轮转偏移量严格按系统工作日序列递推；
     - 选【按每周】：明细表动态展开周一至周日 7 列，周末公休支持值班指定；
     - 选【按每月】：明细表按时间段内各月份展开；
     - 选【按季度】：明细表展开 Q1~Q4 列，适用于季度轮岗换岗。
5. **轮空天数**：
   - 控件类型：数字输入框 (`#batchRollingRestDays`)。
   - 显示条件：仅在排班类型选中【每日轮转】时动态展示。
   - 约束说明：默认值为 `0`，支持输入正整数。
   - 业务规则：控制技术人员执勤一轮后进入轮空休息的天数，期满后重新补入队列。

### 2.4.2 岗位排班明细表及表格操作

#### 2.4.2.1 明细表上方及行内操作
1. **【+ 新增岗位】**：常驻可用。点击打开【岗位选择】穿梭多选弹窗，支持按专业组检索、批量勾选一个或多个岗位并一次性追加至明细表中，自动带出各岗位只读信息及胜任人员池白名单。
2. **【删除】（行操作）**：常驻可用。点击即刻从批量明细表中移除当前行岗位记录，明细表行数与序号自动重新计算。

#### 2.4.2.2 明细表格列定义
1. **序号**：
   - 包含内容：系统连续编号 (1, 2, 3...)。
   - 读写权限：只读。
   - 逻辑说明：随行的增加、删除自动重排。
2. **岗位名称**：
   - 包含内容：岗位中文全称（如 `PCR岗 1`）。
   - 读写权限：只读。
   - 逻辑说明：继承岗位字典正式名称，排班时不可修改。
3. **所属专业组**：
   - 包含内容：专业组名称（如分子检测组、取材技术组、常规病理诊断组）。
   - 读写权限：只读。
4. **关联项目/职责**：
   - 包含内容：展示该岗位对应的检测项目或日常职责文本（如 `肺11、肠四联、BRAF`）。
   - 读写权限：只读。
5. **排班人员**：
   - 控件类型：下拉选择框。
   - 读写权限：唯一可编辑列。
   - 下拉数据源：严格仅加载该岗位预设的胜任人员名单（`competent_pool`）。
   - 模式特定含义：在【每日轮转】模式下，该列代表“首日责任人”，系统以此为基准逐日平移。
6. **操作**：
   - 控件类型：`[删除]` 按钮。
   - 读写权限：可操作。
   - 处理逻辑：点击即刻从批量明细表中移除当前行岗位记录，明细表行数与序号自动重新计算。

### 2.4.3 批量排班弹窗底栏操作
1. **【预览排班】**：
   - 可用条件：明细表存在有效记录。
   - 处理逻辑：点击后执行排班推演并打开全景推演预览大弹窗 (`#modalBatchSchedulePreview`)：
     - 平移排班推演计算：若排班类型为【每日轮转】，系统依据设定的起止时间范围、岗位集合、胜任人员循环池以及【仅工作日】设置，执行环形偏移推演：
       $$\text{staff\_idx} = (\text{day\_idx} + \text{post\_idx}) \pmod{\text{total\_staff}}$$
       - 勾选【仅工作日】时，$\text{day\_idx}$ 仅按系统后台【日历设置】中的实际工作日（上班日）递增计算，遇到法定放假日及周末自动顺延至下一个实际工作日，确保轮转步长不因节假日错位；
       - 未勾选【仅工作日】时，$\text{day\_idx}$ 按连续自然日递增计算；
       - 每日各房间错位分配 1 人，剩余人员自动轮空；结合轮空天数生成全周期逐日排布；
     - 全周期展示：横向展开所选周期的全部工作日与公休日，直观呈现各岗位派发的人员标签；
     - 弹窗内提供【返回调整】按钮，关闭预览继续调整。
2. **【取消】**：
   - 可用条件：常驻可用。
   - 处理逻辑：点击放弃本次批量排班，所有未提交录入数据作废，直接关闭弹窗。
3. **【确认排班】**：
   - 可用条件：必填项完整。
   - 处理逻辑：点击后按序执行以下业务逻辑：
     - 步骤 1（时间合法性校验）：校验起止日期非空，且结束时间不得早于开始时间；
     - 步骤 2（明细非空校验）：校验明细表中每一行的排班人员列均已指定人员，未指定项予以定位提示；
     - 步骤 3（同日互斥校验拦截）：系统自动扫描推演结果中每一天的全科人员分布。若同一人员在同一天被排入了两个及以上关闭兼任的岗位，系统强行阻断保存，弹出错误提示并标红冲突行；
     - 步骤 4（数据批量生效写入）：校验通过后，结合【仅工作日】与排班类型，将推演生成的有效排班数据增量写入排班矩阵大盘；
     - 步骤 5（视图更新）：弹出成功提示，关闭弹窗，排班看板即刻刷新为最新已发布公示态。

## 3.3 待办数据列表

### 3.3.1 列表字段明细
1. **[复选框]**：

3. **岗位名称**：
   - 控件类型：单行文本加粗展示，只读禁用。

4. **任务内容**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：自动回显岗位绑定的工作指引、质控任务或辅助事务；超长文本单行截断省略，鼠标悬浮展示完整文本提示。

   - 控件类型：单行文本展示，只读禁用。

6. **任务开始时间**：
   - 控件类型：单行日期文本展示，只读禁用。
   - 包含内容：自动回显待办周期生效起始日期（格式如 `2026-11-01`）。
7. **任务结束时间**：
   - 控件类型：单行日期文本展示，只读禁用。
   - 包含内容：自动回显待办周期计划截止日期（格式如 `2026-11-30`）。
8. **任务状态**：
   - 控件类型：状态胶囊徽标展示，只读禁用。
   - 状态标识：
     - `[未开始]`：灰底灰字徽标（`#F4F4F5` / `#909399`）；
     - `[进行中]`：蓝底蓝字徽标（`#ECF5FF` / `#008FD5`）；
     - `[已完成]`：绿底绿字徽标（`#E8FFEA` / `#00B42A`）；
     - `[已超期]`：红底红字徽标（`#FFF0F0` / `#F53F3F`）。
   - 状态判定逻辑：
     - **已完成**：已在行内点击【完成】按钮核销的任务。状态锁定为“已完成”，不再受后续时间流转影响；
     - **未开始**：任务尚未核销，且当前系统日期早于任务开始时间（当前日期 < 任务开始时间）；
     - **进行中**：任务尚未核销，且当前系统日期处于任务计划周期内（任务开始时间 ≤ 当前日期 ≤ 任务结束时间）；
     - **已超期**：任务尚未核销，且当前系统日期已超过计划截止日期（当前日期 > 任务结束时间）。
9. **操作**：
   - 控件类型：行内快捷操作按钮组。
   - 交互逻辑：
     - 未完成记录（包括：未开始、进行中、已超期）：并排展示 **`[完成]`** 与 **`[查看]`** 按钮（超期任务依然支持补做核销）；
     - 已完成记录：仅保留展示 **`[查看]`** 按钮。

### 3.3.2 列表操作

2. **【完成】（行操作）**：
   - 可用条件：仅未完成（未开始、进行中、已超期）记录可见并可用。

## 3.4 发起排班待办弹窗 (`modalLaunchTodo`)

**触发源**：由排班大看板顶部操作栏中的 **`[发起待办]`** 按钮点击唤起（参见第 2.1.2 节），用于将当前已排好的矩阵网格正式实例化为员工执行待办任务。

### 3.4.1 控制区表单字段明细

   - 控件类型：日期选择输入框 (`#launchEndDate`)。
   - 约束说明：必填项，默认带入排班周期结束日期；结束时间不得早于开始时间。
   - 联动规则：修改后**不自动触发下方明细表实时刷新**，防止输入过程中频繁重绘或冲掉已编辑的提醒周期；需在下方明细表区域点击【刷新】按钮手动触发重新加载。

### 3.4.2 任务明细表及操作

#### 3.4.2.1 明细表上方操作（列表标题区右侧）
1. **【刷新】**：

2. **【删除】**：
   - 控件样式：线框按钮（无实心填充，仅线框加文字）。
   - 可用条件：勾选一条或多条任务明细。
   - 处理逻辑：
     - 未勾选点击提示：“请先勾选需要删除的任务明细！”；
     - 已勾选点击即刻将所选岗位明细从本次待办发起清单中移除，行数与序号自动重新计算；仅剔除本次待办实例化，不影响底层排班大看板中的排班数据。

#### 3.4.2.2 任务明细表列定义
1. **[复选框]**：
   - 控件类型：表头全选复选框，各数据行独立复选框。
   - 交互逻辑：勾选单行或多行后，联动上方【删除】操作生效。
2. **序号**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：系统连续编号 (1, 2, 3...)，随行的删除自动重排。
3. **岗位名称**：
   - 控件类型：单行文本加粗展示，只读禁用。
   - 包含内容：动态展示所选时间段内有实际排班人员的岗位中文全称。
4. **所属专业组/大类**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：自动回显岗位所属专业组名称（如 `分子检测组`、`取材技术组`）。
5. **任务明细**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：展示岗位绑定的工作指引或质控任务；多个子任务使用中文分号（`；`）分隔展示，超长单行截断并支持悬浮提示。
6. **在岗责任人**：
   - 控件类型：单行文本展示，只读禁用。
   - 包含内容：自动汇总所选时间段内该岗位实际排定的责任人姓名；多人当值以顿号分隔（格式如 `张明、李华`）。
7. **提醒周期**：
   - 控件类型：下拉选择框（选项：`每日`、`每周`、`每月`）。
   - 读写权限：**行内可编辑**。
   - 默认推荐：巡检、消杀类岗位默认推荐 `每日`；常规检测、技术类岗位默认推荐 `每周`。
   - 业务说明：直接决定该岗位待办任务实例化的拆分粒度、周期跨度与生成条数。

### 3.4.3 弹窗操作
1. **【取消】**：
   - 处理逻辑：点击去掉编辑，直接关闭弹窗。
2. **【确认】**：
   - **步骤 1（任务批量实例化）**：根据各岗位设置的【提醒周期】批量生成待办记录（每日每天独立生成 1 条，每周/每月合并生成 1 条周度/月度任务，责任人关联周期内在岗人员）：
     - 每日任务：按自然日逐日拆解，`开始时间 = 结束时间 = 当天自然日 (YYYY-MM-DD)`，精确提取当天实际排班责任人（轮空无排班日不生成）；
     - 每周任务：按自然周聚合，起止时间为选定周期内该周首末日，自动汇总并去重整周在岗责任人（多人以顿号隔开）；
     - 每月任务：按自然月聚合，起止时间为选定周期内该月首末日，自动汇总并去重当月在岗责任人（多人以顿号隔开）。
   - **步骤 2（调用消息模板并发站内通知）**：系统计算各员工分配的待办总数，支持参数控制是否开启任务待办及消息模板：
     - **最简消息模板**：
       - 模板名称：排班待办履职提醒
       - 模板编码：`TMPL_SCHEDULE_TODO_NOTICE`
       - 消息类型：站内通知（系统消息）
       - 消息标题：排班履职待办提醒
       - 消息内容：`${user_name}技术员，您在 ${cycle} 周期内有 ${todo_count} 项排班待办任务，请按时完成履职与核销。`
   - **步骤 3（任务生成）**：关闭弹窗，并刷新待办任务列表。

# 4. 功能页面三：岗位与排班规则维护中心

## 4.1 左侧：岗位大类目录与兼任开关维护

## 4.2 中间：岗位明细数据列表

### 4.2.1 工具栏操作区

3. **【取消】**：仅行编辑态可见。点击放弃修改，还原当前行数据并退出编辑模式。
4. **【删除岗位】**：选中某岗位后可用。点击弹出二次确认提示，确认后从规则库中删除该岗位。
5. **【↑ 上移 / ↓ 下移】**：选中某岗位后可用。点击调整该岗位在看板中的纵向展示顺序。

### 4.2.2 列表展示字段明细（查看态）
1. **序号**：单行文本展示，只读禁用。系统连续编号 (1, 2, 3...)，随行的增删与移位自适应重排。
2. **岗位小类**：单行文本展示，只读禁用。岗位正式名称（如 `PCR岗 1`），主看板纵向呈现的核心工位标识。
3. **所属专业组**：单行文本展示，只读禁用。回显岗位所属专业组（如 `分子检测组`）。
4. **关联项目**：标签组展示，只读禁用。以胶囊标签展示该岗位关联的检测靶标集合，超长文本支持鼠标悬浮查看完整列表。
5. **任务明细**：标签组展示，只读禁用。展示岗位绑定的日常指引与质控任务。
6. **胜任人员**：标签组展示，只读禁用。展示具备该岗位资质的技术人员白名单。

## 4.3 岗位编辑功能说明

通过在岗位列表工具栏点击 **【编辑】** 或 **【+ 新增岗位】** 进入岗位行编辑态。系统支持对岗位基础信息、关联项目、工作任务及胜任人员进行系统化维护。

### 4.3.1 岗位编辑字段明细与穿梭选择规范

1. **岗位名称（岗位小类）**：
   - **控件类型**：单行文本输入框。
   - **约束说明**：必填项。
   - **业务含义**：输入工位的标准名称（如 `PCR岗 1`、`常规制片岗`）。
   - **业务联动说明**：直接作为排班矩阵看板纵向表头核心标识，以及待办任务的岗位名称唯一来源。

2. **所属专业组**：
   - **控件类型**：下拉选择框。
   - **约束说明**：必填项。
   - **选项内容**：分子检测组、取材技术组、病理诊断组、会诊/质控组、科室管理组。
   - **业务联动说明**：决定该岗位在排班大盘纵向分组中的归属，以及看板顶部【所属专业组】下拉筛选的联动过滤。

3. **关联项目**：
   - **控件类型**：标签展示区 + 右侧 **`[...]`** 穿梭弹窗唤起按钮。
   - **约束说明**：选填，支持多选。
   - **穿梭选择弹窗规范 (`#ruleProjectPickerModal`)**：
     - **左侧可选项目库**：展示预设检测项目库（如肺11、肠四联、BRAF、WT1-PCR、15种融合基因、HER2扩增等）；顶部提供搜索框，输入关键字实时模糊过滤可选项目；
     - **右侧已选项目池**：以浅蓝底胶囊徽标展示已选中的项目标签；单个标签点击 `×` 可快速移除，右上角提供【清空全部】按钮；
     - **自定义项目录入**：底部提供“自定义项目输入框”与【+ 添加】按钮，支持手动录入非标或临时检测项目，校验非空且不重复后直接追加至右侧已选池；
     - **弹窗底栏操作**：
       - 【取消】：放弃本次弹窗内的修改，直接关闭弹窗；
       - 【确定】：将右侧已选项目集合持久化回写至当前岗位行的【关联项目】列。
   - **业务联动说明**：回显至排班矩阵大盘第 3 列【关联项目】与批量排班明细中，直观展示该工位承接的具体检测技术靶标。

4. **任务选择（任务明细）**：
   - **控件类型**：标签展示区 + 右侧 **`[...]`** 穿梭弹窗唤起按钮。
   - **约束说明**：选填，支持多选。
   - **穿梭选择弹窗规范 (`#ruleTaskPickerModal`)**：
     - **左侧内置任务库**：按专业分类呈现标准操作规范与质控职责（如核酸提取、PCR扩增上机、文库构建、FISH杂交、曲线质控分析、温湿度监控等）；顶部提供搜索框实时过滤；
     - **右侧已选任务池**：以浅绿底胶囊徽标展示已选中的任务指引标签；单个标签点击 `×` 快速移除，右上角提供【清空全部】按钮；
     - **自定义任务录入**：底部提供“自定义任务输入框”与【+ 添加】按钮，支持手动录入科室特定或临时指引，点击追加至右侧已选池；
     - **弹窗底栏操作**：
       - 【取消】：放弃本次弹窗内的修改，直接关闭弹窗；
       - 【确定】：将已选任务集合持久化回写至当前岗位行的【任务明细】列。
   - **业务联动说明**：在主排班大盘中作为岗位日常职责悬浮查看；**当用户点击【发起待办】时，系统自动提取此处配置的任务明细作为待办任务执行内容**，驱动技术员日常闭环履职。

5. **胜任人员**：
   - **控件类型**：标签展示区 + 右侧 **`[...]`** 穿梭弹窗唤起按钮。
   - **约束说明**：必填项，至少配置 1 名在职技术人员。
   - **穿梭选择弹窗规范 (`#rulePersonPickerModal`)**：
     - **左侧已授权人员库**：严格联动科室资质授权档案库，仅加载具有相应专业岗位上岗资质的在职技术人员；顶部提供搜索框，输入姓名拼音或汉字实时模糊过滤；
     - **右侧已选胜任人员池**：以浅灰底徽标展示已纳入胜任人员池的名单，支持单个点击移除；
     - **弹窗底栏操作**：
       - 【取消】：放弃本次人员调整，关闭弹窗；
       - 【确定】：将已选人员白名单持久化回写至当前岗位行的【胜任人员】列。
   - **业务联动说明（排班资质核心防线）**：此处配置的人员是**排班矩阵单日排班弹窗、批量排班弹窗中“排班人员”下拉列表的唯一真理源**。系统实施强资质准入控制，未配置在胜任人员白名单中的员工，绝不允许排入该岗位。

### 4.3.2 岗位编辑操作逻辑
1. **【取消】**：
   - 可用条件：处于行编辑状态。
   - 处理逻辑：点击放弃当前行未保存的编辑内容，数据还原为编辑前的值并退出行编辑状态。
2. **【保存】**：
   - 可用条件：处于行编辑状态。
   - 处理逻辑：点击后按序执行以下校验与生效流程：
     - 步骤 1（非空校验）：校验岗位小类名称非空，未填提示“请输入岗位名称”；
     - 步骤 2（专业组校验）：校验所属专业组已选择；
     - 步骤 3（胜任人员校验）：校验胜任人员池至少配置 1 人，未配置提示“胜任人员不能为空，请至少添加一名人员”；
     - 步骤 4（行数据持久化）：校验通过后，持久化当前行数据，切换回只读展示态；
     - 步骤 5（全局联动更新）：点击页面底部【保存配置】按钮后，将规则全量同步生效至全局岗位注册中心 (`POST_REGISTRY`)，排班大盘即刻按最新岗位配置刷新。

# 5. 核心业务规则与智能防呆校验引擎

## 5.1 四大解耦业务规则
1. **概念彻底解耦**：严格遵循“岗位 ≠ 检测方法 ≠ 检验靶标 ≠ 辅助杂务”。切蜡块、转运、试剂盘点独立建岗建库，严禁计入临床检测项目统计。
2. **同名异法独立建项**：针对同靶标不同技术路线，按“项目+方法”独立维护。例如 `WT1-PCR` 归入 PCR 岗位，`WT1-FISH` 归入 FISH 岗位；`PDGFRA突变检测(PCR)` 与 `PDGFRA/KIT双基因测序` 独立管理。
3. **主辅分类兼任放行**：兼任属性由岗位大类统一收敛维护。关闭兼任的大类执行冲突互斥阻断；开启兼任的大类允许与主岗位在同一天并行排班。
4. **房间安全巡查解耦**：物理房间安全巡检与技术人员专业工位解耦，按房间代码循环平移。

## 5.2 提交时防呆校验引擎
系统严格在**点击批量排班【确认排班】按钮提交时**执行统一防呆校验：
1. **核心阻断级校验（强制拦截保存）**：
   - **同日非兼任岗位互斥**：在同一自然日内，**一个人只能排一个非兼任岗位（即关闭兼任的主技术岗位）**；
   - 属于开启兼任大类的辅助/巡检岗位允许与主岗位在同一天并行兼任；
   - 若提交时检测到同日排入了多个非兼任岗位，立即弹出 Toast 拦截提示并标红冲突行，禁止保存。
2. **胜任资质准入约束**：
   - 下拉选人时，严格仅展示属于该岗位“胜任人员白名单池”内的人员，从源头杜绝非胜任人员误排。
